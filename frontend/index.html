VaporStore REST API Documentation

VaporStore is an enterprise-grade RESTful API built on FastAPI, SQLAlchemy 2.0+, and SQLite/PostgreSQL. It implements a strict 1:N Relational Model connecting Categories and Video Games with enforced foreign key constraints and cascade rules.

Base URL: /api/v1 • Open API Specs: Swagger UI | ReDoc

GET /api/v1/health
Check API service and database connectivity

Returns health status, application version, database connectivity, and timestamp.

GET /api/v1/categories/
List all categories with live game counts

Retrieves all available categories ordered alphabetically, each annotated with its computed count of associated games.

// Click "Test in Browser" to execute live request...
POST /api/v1/categories/
Create a new category (Unique name required)

Returns HTTP 201 Created on success, or HTTP 400 Bad Request if the name is already taken.

{
  "name": "Action RPG",
  "description": "Role-playing experiences focused on real-time combat and rich lore."
}
GET /api/v1/games/
Query games with search, relational category filter & pagination

Supported query params: page, page_size, category_id, search, min_rating, max_price, is_active. 

// Click "Test in Browser" to execute live request...
POST /api/v1/games/
Create a new game linked to a valid category

Returns HTTP 201 Created on success, or HTTP 400 Bad Request if the foreign key category does not exist.

{
  "title": "Elden Ring",
  "description": "Rise, Tarnished, and let grace guide thee.",
  "price": 59.99,
  "release_year": 2022,
  "rating": 9.6,
  "steam_app_id": 1245620,
  "is_active": true,
  "category_id": 1
}
DELETE /api/v1/categories/{id}
Delete category with automatic relational CASCADE

⚠️ Relational Integrity: Deleting a category automatically cascades and deletes all associated games from the database.

GET /api/v1/steam/search
Search public Steam Store catalog by keyword

Searches official Steam catalog with zero developer API key requirement. Parameters: query (required), limit. 

// Click "Test in Browser" to execute live request...
POST /api/v1/games/steam/{app_id}
1-Click Import game from Steam (Auto-links/creates Category)

Retrieves complete metadata (title, short description, price, release year, Metacritic rating) from Steam, auto-creates the corresponding Category if missing, and saves the Game into the database.

GET /api/v1/games/{id}/steam-stats
Fetch live concurrent players from Steam

Queries real-time player counts directly from Steam Web API for any game with an associated Steam AppID.
